# Site de Balé — projeto básico

Este projeto usa somente HTML e CSS, sem frameworks ou ferramentas adicionais.

## Estrutura

```text
site-bale-projeto-basico/
├── index.html
├── style.css
├── README.md
└── assets/
    └── logo.png
```

## Como abrir

1. Mantenha os arquivos nessa estrutura.
2. Abra `index.html` no navegador.
3. Edite os textos e links no `index.html`.
4. Edite cores, fontes e tamanhos no `style.css`.

## Onde encontrar cada parte

No HTML, procure pelos comentários: Cabeçalho, Apresentação, Professora, Turmas, Horários, Diferenciais, Espaço, Localização, Contato e Rodapé.

No CSS, os nomes das classes são descritivos:
- `.cabecalho`: menu do topo.
- `.inicio`: primeira seção.
- `.cartao`: cartões das turmas.
- `.galeria`: espaços das fotos.
- `.formulario`: formulário de contato.
- `.rodape`: final da página.

## Antes de publicar

- Troque os espaços reservados por fotos reais.
- Atualize telefone, WhatsApp e Instagram.
- Confirme endereço, horários e informações das turmas.
- Insira o mapa real.
- Conecte o formulário a um serviço de envio. No momento, ele apenas exibe um aviso.

As fontes Cormorant Garamond e Jost vêm do Google Fonts e precisam de conexão com a internet.
